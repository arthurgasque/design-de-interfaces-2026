O que são Algoritmos?

Um algoritmo é uma sequência finita e ordenada de passos bem definidos que, quando seguidos corretamente, resolvem um problema ou executam uma tarefa específica. Todo programa de computador é, em sua essência, a implementação de um ou mais algoritmos. Bons algoritmos fazem a diferença entre um software rápido e responsivo e um sistema lento que trava.

A análise de algoritmos permite comparar soluções diferentes para o mesmo problema e escolher a mais eficiente, considerando tempo de execução e uso de memória. Para isso, utilizamos a Notação Big-O, que descreve como o desempenho de um algoritmo cresce em relação ao tamanho da entrada.

Principais Estruturas de Dados

Estruturas de dados são formas de organizar e armazenar informações na memória do computador de maneira que possam ser acessadas e modificadas de forma eficiente. A escolha da estrutura correta pode reduzir drasticamente a complexidade de um algoritmo. Confira as principais estruturas abaixo:

  • Array (Vetor): sequência de elementos do mesmo tipo armazenados em posições contíguas de memória.
  • Lista Ligada: coleção de nós onde cada nó armazena um dado e um ponteiro para o próximo nó.
  • Pilha (Stack): estrutura LIFO, o último a entrar é o primeiro a sair.
  • Fila (Queue): estrutura FIFO, o primeiro a entrar é o primeiro a sair.
  • Árvore Binária: estrutura hierárquica onde cada nó possui no máximo dois filhos.
  • Grafo: conjunto de vértices conectados por arestas, usado para modelar redes e relacionamentos.
  • Tabela Hash: estrutura que mapeia chaves a valores usando uma função de hashing.

Árvore Binária de Busca

A Árvore Binária de Busca (BST) é uma das estruturas mais importantes da computação. Em uma BST, para cada nó, todos os valores da subárvore esquerda são menores e todos os da subárvore direita são maiores. Isso permite operações de busca, inserção e remoção com complexidade O(log n) em média.

Algoritmos de Ordenação

Algoritmos de ordenação organizam elementos em uma sequência definida (crescente ou decrescente). A tabela a seguir compara os principais algoritmos quanto à complexidade de tempo e ao uso de memória extra:

Comparativo de Algoritmos de Ordenação
Algoritmo Melhor Caso Caso Médio Pior Caso Memória Extra
Bubble Sort O(n) O(n²) O(n²) O(1)
Selection Sort O(n²) O(n²) O(n²) O(1)
Insertion Sort O(n) O(n²) O(n²) O(1)
Merge Sort O(n log n) O(n log n) O(n log n) O(n)
Quick Sort O(n log n) O(n log n) O(n²) O(log n)
Heap Sort O(n log n) O(n log n) O(n log n) O(1)
Fonte: Cormen, T. H. et al. Algoritmos: Teoria e Prática. 3ª ed.
